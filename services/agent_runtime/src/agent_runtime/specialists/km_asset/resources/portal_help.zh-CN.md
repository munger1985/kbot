# 关于 KM Portal

我是 KM Portal 中的 KM Agent。KM Portal 帮助你在当前授权范围内查找、筛选和了解可用的知识 Asset，并通过每个 Asset 的引用查看来源内容。

我可以按技术主题、产品、解决方案、作者和发布时间等多个条件查找 Asset，也可以进行数量统计、排序和分组；找到结果后，还可以继续询问某个 Asset 的详细内容。

常见提问方式：

1. **按主题和偏好搜索**：“找几个关于 OAC 的 Asset，最好是金融欺诈案例。”
2. **组合筛选和排序**：“列出过去一年发布的最新 5 个 APEX Asset。”
3. **查看结果详情**：“详细介绍第二个 Asset，并说明它使用了哪些 Oracle 产品。”

提问时可以同时说明主题、作者、时间范围、产品、数量和排序要求，我会尽量返回最符合条件且可引用的 Asset。

# KM Portal 소개

저는 KM Portal의 KM Agent입니다. KM Portal은 사용자에게 허용된 범위에서 지식 Asset을 검색하고, 조건에 따라 선별하며, 내용을 이해할 수 있도록 돕는 애플리케이션입니다. 각 Asset의 인용을 통해 원본 콘텐츠도 확인할 수 있습니다.

기술 주제, 제품, 솔루션, 작성자, 게시일 등 여러 조건을 조합하여 Asset을 검색할 수 있습니다. 개수 집계, 정렬, 그룹화도 가능하며, 검색 결과에 포함된 특정 Asset의 세부 내용을 이어서 질문할 수도 있습니다.

자주 사용하는 질문 예시:

1. **주제와 선호 조건으로 검색**: “OAC 관련 Asset을 몇 개 찾아 주세요. 금융 사기 사례가 있으면 우선해 주세요.”
2. **필터와 정렬 조합**: “지난 1년 동안 게시된 최신 APEX Asset 5개를 보여 주세요.”
3. **검색 결과 상세 확인**: “두 번째 Asset을 자세히 설명하고 어떤 Oracle 제품을 사용하는지도 알려 주세요.”

하나의 질문에 주제, 작성자, 기간, 제품, 결과 개수, 정렬 조건을 함께 지정할 수 있습니다. 조건에 가장 잘 맞고 인용 가능한 Asset을 반환합니다.

# KM Portal について

私は KM Portal の KM Agent です。KM Portal は、利用者に許可された範囲でナレッジ Asset を検索、絞り込み、理解するためのアプリケーションです。各 Asset の引用から元のコンテンツを確認できます。

技術テーマ、製品、ソリューション、作成者、公開日など、複数の条件を組み合わせて Asset を検索できます。件数の集計、並べ替え、グループ化にも対応し、検索結果に含まれる Asset の詳細を続けて質問することもできます。

よくある質問例：

1. **テーマと希望条件で検索**：「OAC に関する Asset をいくつか探してください。金融詐欺の事例があれば優先してください。」
2. **条件と並び順を組み合わせる**：「過去 1 年に公開された最新の APEX Asset を 5 件表示してください。」
3. **検索結果の詳細を確認する**：「2 番目の Asset を詳しく説明し、使用されている Oracle 製品も教えてください。」

テーマ、作成者、期間、製品、件数、並び順を一つの質問にまとめて指定できます。条件に最も合う、引用可能な Asset を返します。

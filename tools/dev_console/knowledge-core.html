资源准备

创建隔离边界，选择模型并建立 Collection。点击列表记录可把 Collection Key 带入后续步骤。

创建 Domain

创建成功后自动更新页面顶部的 Domain ID。

Collections

点击一行即可选中，并同步到上传、审批和绑定表单。

Key名称状态Collection ID

创建 Collection

Collection ID 由后端生成 UUIDv7；模型选项来自 Model Catalog，文本 Embedding 创建后不可更换。

02

文件入库与处理

直接上传单文件或 Bundle，完成人工审批，并持续跟踪解析、画像与索引状态。

上传文件

EACH_FILE 为每个文件建立独立 Bundle；SINGLE_BUNDLE 将所有文件放入同一个 Bundle。

用户上传审批

只有 USER_UPLOAD 强制审批；批准后才创建解析任务。

标题/文件Revision ID操作

文件入库跟踪

每 2 秒刷新，覆盖上传、审批、解析、索引和可检索状态。

文件 / Bundle当前阶段审批 文件明细Bundle / Revision最近刷新

Bundle 状态精查

需要查看原始状态 DTO 时使用；日常流程优先查看上方跟踪表。

数据库与监控数据源

数据库凭证仅填写 Secret 引用；留空时聊天流程会在证据不足时要求用户手工执行 SQL。

创建数据库目标

用户名和密码必须成对填写；仅在本次提交时传输并加密保存，创建后不会再次显示。

不填写数据库 Endpoint 时仍可绑定监控源；聊天证据不足时，Agent 会给出只读 SQL 供用户手工执行。

诊断能力声明

应与只读账号实际可访问的系统视图一致；声明错误会在诊断结果中形成证据缺口。

创建监控源

必须填写支持 /api/v1/query_range 的 Prometheus Server 地址；Exporter 的 :9161/metrics 不能直接作为查询端点。

# AIOps 资料检索

「知识资产 → 资料检索」独立于 Agent 工作台，供当前工作域具有 `aiops:knowledge_manage` 的用户查询。用户输入正文查询，选择运维资料或诊断案例；运维资料可进一步选择启用的知识库。结果按资料版本归组，显示命中片段，不创建会话，不生成诊断或处置建议。

- 运维资料只搜当前工作域启用的知识库，且保持已有资料目标范围约束。未发布、已撤回或索引未就绪的版本不会作为命中返回。
- 诊断案例不依赖用户选择 Agent 或手册知识库；仍逐条核验源报告、源运行、源 Agent 的当前目标和数据源权限、案例效果记录及规范正文，历史案例仅供参考。
- 使用既有 AIOps 检索索引与发布校验，管理查询委托不能用作 Agent 或历史查询凭证。交付前复核精确发布版本、解析与索引代次；区分无符合条件的资料、无正文命中和检索未充分核验。
- 召回只是候选。显示前逐段校验正文，查询的完整成分在同一句提供直接支持时优先；其他候选须经结构化语义判断，且支持引文必须来自同一片段。标题、所属库和召回名次不能单独作为命中依据；不足上限时不回填。
- 手册的语义校验复用所选资料所属库已授权的正文分类模型（`parser_llm`），案例只用本域案例集合的 `retrieval_llm`。通过现有 Prompt 初始化流程装载 `aiops_agent.passage_relevance`（`1.0.0`）；模型或 Prompt 不可用时仍展示可从正文直接核对的命中，并明确标识部分候选未核验。
- KBot4：`POST /api/v1/apps/aiops/operations-knowledge/search`；Ammolite：`POST /api/v1/apps/aiops/domains/{domain_code}/ops/operations-knowledge/search`。现有 `search-preview` 仍要求 Agent，权限和行为不变。

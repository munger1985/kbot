# MySQL 版本支持

AIOps 目标支持 MySQL 5.7 和 8.4；连接测试核验真实版本，不允许把 5.7 声明成 8.4。
5.6、8.0 等未发布版本档案仍被拒绝。5.7 已停止社区维护，仅建议用于隔离的开发测试。

## MySQL 5.7

- 支持目标及诊断凭据配置、版本/能力探测，以及 Prometheus/Zabbix 的 mysql-overview 七项指标。
- 发布 15 项只读诊断变体：实例身份、活动会话、当前 SQL、阻塞链、逻辑容量、长事务、
  空闲会话、连接利用率、实例吞吐、实例性能、实例参数、对象候选、索引列、表统计、复制状态。
- 阻塞链使用 INNODB_LOCK_WAITS/INNODB_TRX；索引目录不读取 8.x 的 IS_VISIBLE。
  5.7 的既有索引均可见，无索引行仍保留空值。
- 执行前仍检查真实能力与权限；版本支持不代表账号具备全部诊断权限。
- 8.x 专属锁、直方图/统计健康、视图依赖目录和复制延迟等诊断不匹配 5.7；
  未验证的其他诊断同样不下放。5.7 不发布自动变更动作，不能终止业务会话。

监控逻辑容量来自 Exporter 的表大小序列。空 schema 没有表序列时显示无数据缺口，
不伪造零值、容量上限、磁盘容量，也不自动创建业务表。实例其他指标仍可独立展示。

这次支持不修改应用持久化结构，不自动重启服务或数据库。
已运行的 Python 服务需按正常发布流程加载新代码，静态页面按各平台发布流程更新。

## 统一交付规则

Ammolite 与 KBot4 采用相同语义：

1. 需要的自动取证安排在正文生成前。已有正文后，即使有 `next_evidence`、
   延后动作或确定性缺口，本轮也不自动重规划或再次调用模型；缺口保留为后续建议。
   尚无正文的必要补证、权限和审批流程不变。
2. SQL 回答组合只复用已生成正文。结构化检查点失效或尾部核验失败不触发再次生成；
   正文保留，核验状态另行说明。
3. 以已提交的模型 `answer.delta` 作为用户已见文本的依据。在最终工件计算 Hash、
   落库之前归一正文，避免 Artifact、消息和展示块各自保存不同版本。
   不修改历史冻结工件，不增加数据库字段。
4. 最终正文相同或仅向后扩展时正常交接；若最终摘要与已见正文冲突，保留原文并标记
   `UNVERIFIED`，不赋予证据引用、已核验结论或执行授权。重复完成不重复写入或回放。
5. Portal 和 KBot 均保持同一正文气泡。终态错误、空正文、截断或回读失败不能清空已显示文字。
   原文和最终核验状态独立展示，不以显示原文代替结构化审批。

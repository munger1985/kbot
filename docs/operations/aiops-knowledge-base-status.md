# 运维知识库启停

知识库管理卡片使用统一目录卡片规格。启停操作与名称、说明、模型配置保存相互独立，
不因为缺少模型配置而禁止停用，也不隐式切换向量模型或重建索引。

- `ACTIVE`：可绑定到 Agent、接收新资料并参与经授权的知识检索。
- `DISABLED`：不再允许新上传、Agent 新绑定或检索使用；已有资料、模型配置、
  索引和 Agent 历史绑定原样保留，管理者仍可查看、编辑及重新启用。
- `ARCHIVED`：不是可启停状态，不允许通过启停接口恢复。
- 删除仍按资料和当前 Agent 版本的引用情况单独保护；停用不会解除引用。

公开接口在当前 App / Domain 的 operations-knowledge 路径下提供
`POST /knowledge-bases/{knowledge_base_id}:enable` 与 `:disable`。
内部接口具有相同操作语义；公开入口要求 `aiops:knowledge_manage`，内部入口要求
`aiops.manage` 服务范围及可信 Domain 上下文。两端操作体均只接受：

```json
{"expected_row_version": 7}
```

事务内按当前 Domain 加锁读取；版本过期返回 412，丢失或不可管理状态返回 404。
有效的重复操作不改写版本。卡片在服务端成功后重新读取状态；停用前需确认，
资料上传选择器只展示启用的知识库，管理列表仍保留停用库以便查阅已有资料。

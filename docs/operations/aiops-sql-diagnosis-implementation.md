- 有限候选/有界可见集合设置，真实采样边界和覆盖、源版本/已识别重置处理，
  NULL Schema 与空字符串区分，PG 多维身份和精确差分、不相减极值。
- 默认交互绝对 deadline、模型和 Worker 预算、重规划汇总预留，

## 不同 SQL 比较的代码闭环

同一已授权 Target/引擎内 2–4 个独立 SQL 请求可使用 SQL_COMPARISON 进入完整调查，
共享历史搜索和证据投影预算。逐请求/主体分别取证与诊断，缺项不整体丢弃；不能把
只分析其中一条、仅比较同标识内部主体或累计数值当作完成跨 SQL 窗口比较。
完成门禁要求全部请求完整、每主体已核验结论齐全，并有连接全部请求的比较判断。
两端表格从各自来源行取值，逐行时间/口径和原始选行引用不丢失；
多主体对象图冻结到调查/报告并逐图重放，案例/报告来源复核覆盖每份原始工具 Artifact。
无模型或字段校验失败仍为部分摘要。无 DDL、无线上权限/采集修改，未部署、重启或发布 Prompt。

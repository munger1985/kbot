# 业务系统新增与编辑字段对齐

日期：2026-11-05。适用 KBot4 与 Ammolite Cube。

后续资源绑定改造已替代本文的嵌套主机配置，当前规则见[统一资源监控绑定](aiops-resource-monitoring.md)。
本次完成代码、本地模拟回归和构建；尚未部署或对真实业务系统执行写入验收。

## 页面入口

AIOps 配置 → 业务系统 → 新增，或编辑已下线的业务系统 → 系统构成 → 数据库资源。
运行中的业务系统仍只读，不通过修改页面绕过生命周期规则。

已有数据库与新增数据库复用连接、访问凭据和监控字段。
修改监控源不重建数据库资源或 Target，不删除历史诊断、业务关系和其他监控映射。

## 字段核对表

| 字段 | 新增 | 已有资源编辑 |
| --- | --- | --- |
| 业务系统名称、环境、重要等级、责任组、说明 | 可填写 | 可修改 |
| 数据库名称、技术责任组、位置 | 可填写 | 可修改；已有 RAC 按节点编辑资源名称 |
| RAC 名称 | 可填写 | 可修改集群关系名称，不覆盖已有节点资源名称 |
| 数据库引擎 | 可选择 | 展示但只读，不原地转换数据库引擎 |
| 数据库版本、环境、角色 | 可填写 | 可修改 |
| 部署形态（单实例/RAC） | Oracle 可选择 | 展示但只读，不原地重构已有节点拓扑 |
| RAC 节点编号 | 新建 RAC 时可填写 | 展示但只读；节点身份不能直接改号 |
| 数据库地址、端口、Service Name / Database | 可填写 | 可修改；保留原 Target 身份 |
| Oracle 容器范围、PDB 名称 | 可填写 | 可修改；校验引擎、范围及已有 OEM 映射的一致性 |
| TLS 开关（MySQL/PostgreSQL） | 可选择 | 回显并可修改，不覆盖已有配置为页面默认值 |
| TLS Profile（PostgreSQL，启用 TLS 时） | 可选 | 回显并可修改；仅使用服务端已配置 Profile |
| 诊断用户名 | 可填写 | 回显并可修改 |
| 诊断密码 | 必填 | 不回显；留空保留原密码，可单独更新用户名或密码 |
| 监控源、数据库候选 | 可选择 | 回显原映射，可重新发现及选择 OEM 等来源与目标 |
| Prometheus / OEM 主机候选 | 在独立主机资源中选择；容器仅支持 OEM | 在独立主机资源中回显和修改，不嵌套在数据库内 |
| 多个监控映射 | 首次创建映射 | 明确选择要修改的绑定，或新增；其他映射保留 |
| 历史 SQL 采集策略 | 可配置 | 可修改，随发布生效 |
| 资源关系 | 可配置 | 按原有关系规则修改；RAC 成员身份不通过属性编辑改变 |

数据库密码的留空语义只用于已有凭据。新资源没有已保存密码，不能以留空代替凭据。
“测试连接”可用已保存凭据测试当前尚未保存的连接参数；不会写入资源、凭据或连接状态。

## 服务端边界

- DatabaseResourceView 回传 Target 版本与当前有效监控绑定，不回传密码。
- DatabaseResourcePatch 扩展连接、凭据与监控编辑字段；未提交字段保持不变，不能显式清空密码。
- 连接、监控、采集策略变更必须提交业务系统 ID、关联资源 ID、Target 版本，
  并检查 Domain/Tenant、资源归属和业务系统已下线状态。
- 监控改绑明确提交原绑定 ID 和版本。新建及修改共用候选解签、过期/作用域校验、
  Provider 重读、定位冲突与 Oracle 引擎/容器/RAC 实例核验，不能手填 GUID 绕过。
- 同一资源的连接、凭据、映射和采集策略在同一 UoW 内更新。
  既有业务系统整体编辑仍沿用分步接口，不宣称整个工作区发布是单一原子事务。
- 更新指定绑定时保留 Binding ID、角色、优先级与原有预算等配置；其他绑定不变。
- 真正修改连接或凭据后重置旧连接观测并请求重新检查；未改连接不重复触发。
- 资源修改成功后更新页面中的资源/Target/绑定版本并清除已提交密码，避免后续步骤失败重试时重放旧版本。
- 本段描述前一轮字段对齐；当前统一资源绑定已变更 Schema，详见上述后续文档。

三版共同修正

不支持读取 ≠ 查询失败 ≠ 设备故障；管理可达 ≠ 硬件健康。

结构对象不占用状态卡，CPU/内存不在清单与指标区重复；上下限与配置值单独收纳。

真实硬件子组件仍需纳管与身份核验。本次设计不凭父设备状态生成风扇、电源或整机健康。

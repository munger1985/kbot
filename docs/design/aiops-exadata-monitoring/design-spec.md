# Exadata OEM 监控重设计 · A 整机首页＋B 设备详情

## 目标与当前问题

本设计仅针对 EXADATA 资源且监控来源为 OEM 的专用页面，Ammolite 与 KBot4 同步实施；普通 OEM、非 Exadata、Prometheus 监控和数据库诊断不改动。受众是需要快速核查节点、状态、性能和缺口的运维人员，不是阅读 OEM 原始导出的开发者。首屏应回答：哪些设备已确认、哪个节点有有效采样、管理可达与硬件健康各自怎样、CPU/内存是否变化。当前清单混入整机/Grid/Rack 等结构对象，重复显示 CPU/内存，并把无独立状态、未采样、不支持及读取失败混用，造成首屏拥挤和故障感。

当前真实证据来自 2026-11-12 14:25 正常登录会话的公开 view API，以及用户提供的六 CSV 压缩包；不是设计 fixture。概览七个确认对象，其中四个是节点或设备，三个是结构对象；十二项查询、九条采样，DB Server Response 无数据，交换机和 PDU 父 ComponentState 为 SOURCE_QUERY_UNSUPPORTED。Cell 资源另十二项查询均有有效采样。数字样稿固定展示这一时点，不定时刷新、不调用 OEM、不伪造历史曲线。样稿明确标示“设计预览 / 固定快照”；它不是已部署产品。

## 核心结构

主工作区为整机概览、DB Server、Cell、磁盘 IO、Flash / Smart IO、IORM、互联设备和容量。整机概览首先按设备类型组织节点资源：DB Server 与 Cell 分开，服务状态用紧凑标签而非数值卡，CPU/内存同节点对齐。管理可达性与硬件组件健康分列；不能因交换机 AP=UP 就把交换机或整机标成健康。DBM/Grid/Rack 默认作为资产结构条或折叠资产目录出现，不再占用状态大块，也不逐项重复“此类目标尚无……”说明。

节点详情保留现有指标卡、维度、历史、7 天/30 天基线、采样数和原始证据。状态不请求均值。阈值、上下限、配置和标识进入“配置与原始值”，不与负载性能平铺；OEM 未声明单位时不擅加摄氏度。一次采样不绘制假趋势，不跨设备汇总均值，原厂带维度月历史限制保持。基线和最新采样时间分别标示，精确计算由后端负责；样稿中的空历史是未查询而非零。

缺口用清晰短标签：不支持读取、未采样、查询失败、采样过期、未知状态、未查询。这些是数据质量，不是设备健康。主界面只给一个简短缺口入口；展开后显示节点、指标、错误码和采样时间，不反复堆政策说明。读取失败不隐藏、不转绿；无独立状态的结构对象不显示红色错误。

## 正式实施建议与边界

后端需以结构化 gap.code 区分 SOURCE_QUERY_UNSUPPORTED 与网络/5xx/解析失败，保留原始错误证据；不能单凭空数据自动认定“不支持”。ComponentState 必须同时核对父设备与真实硬件子组件身份，父上无样本不能证明子组件无状态。导出中服务器子组件 82 条 OK、3 条空值，交换机子组件 12 条 OK；模拟环境尚未建立这些子组件。需使用 OEM 官方组件目录与父归属，逐个复核 GUID、类型、父目标并受现有绑定确认范围控制，不能构造 GUID 或以同 Agent 推断归属。现有快照无法证明的状态不得填 OK。

初稿阶段仅设计、只读核查及可运行 HTML。用户确认后，正式实施将设计规则落实到类型化展示模型、后端取证合同、Vue 和 KBot JS，两端同步回归与线上验收；不通过 CSS 掩盖采集缺口，不改模拟器、绑定、数据库或 Prompt。

## 视觉与交互约束

统一 1440×1000 桌面样稿，并验证 768×1024、390×844；正文 14–15px，注释不低于 12px。沿用 Noto Sans SC / IBM Plex Mono 角色、现有钢蓝与中性灰 tokens、语义绿色/琥珀色；深色来自既有暗色 tokens。保留现有 AppShell 和上层 Target 导航，只设计 Exadata 内容区，不再套一层全局侧栏。不需要照片、机柜装饰画或厂商宣传素材；现有 Ammolite favicon 原样内嵌。必要图片仅是页面对比截图。

A 以 Carbon 数据表的分组和展开为参照，适合整机首屏与逐节点对照；B 以 Dieter Rams 的减法和对象聚焦为思考锚点，适合持续排查一个设备；C 将轮盘第 4 项的几何模块/明确交互层级转为现有产品暗色监测矩阵，不采用糖果配色或营销字体，适合密集巡检。三版同数据、不同结构，不以换色充当不同方案。

## 方向确认

用户已确认“A 做整机首页＋B 做设备详情”。整机首页采用 A 的节点资源/互联供电分区及折叠资产结构；选择设备后采用 B 的设备目录与详情工作区，按服务状态、性能负载、配置原始值分别展示。方向原话、初稿路径与实施边界见 direction-approved.md。

## 信息与操作

- 上下文栏展示可用 Agent、允许披露的库绑定和本次可用的问文／问数能力。切换 Agent 时沿用现行会话约束，不把旧消息接入不同 Agent 的新运行。未绑定／库停用／无 READ 时明确「本次不可问文」，独立问数是否可发按既有合同；不可披露时不展示库名。
- 会话列表仅展示本人在当前 Agent 下的会话。桌面默认收起，左栏顶部纵向排列三横开关与居中的新增图标，下方保留会话缩略标题及当前会话高亮。展开时顶部两个按钮从左到右排列，历史按日期分组，显示完整会话标题及最近活动时间；悬停或聚焦会话行时显示竖排三点（触屏直接显示）。仅从三点菜单进入「删除会话」，继续使用危险操作确认。窄屏收起时左栏保留两个操作按钮；展开时在聊天上方显示列表，选择或新增会话后收起。
- 消息区展示用户问题、助手回答、流式阶段、终止和真实错误。用户消息靠右，Agent 回答靠左。发问区沿用 AIOps 的附件、输入、发送布局，图片仅在支持时可选，选择后可移除；Enter 发送，Shift + Enter 换行，也可点击发送；输入法选字不触发发送。数据／混合呈现沿用现有业务，不再出现直接检索表单、模型下拉或独立库选择。
- 回答内引用使用 Runtime 返回的真实标签（如 `[D1]`），不在回答下方重复列引用。问数标签继续沿用现有语义。

## 引用与检索结果：方案 B 迭代

[选定稿与确认记录](chat-references/direction-approved.md)

| 入口 | 打开内容 | 降级行为 |
|---|---|---|
| 回答正文中的文档编号 | 直接打开宽版右侧原文抽屉，沿用直接检索的 PDF 阅读器，跳到冻结引用的原文页并滚动到可核实的命中段落，标黄匹配文字 | 找不到可靠的文字与坐标对应时只定位到页；无 PDF 或 PDF 不可读时仅展示仍获授权的本轮摘录或图片证据，不假标黄、不使用新版替换 |
| 回答下方「查看检索结果」 | 独立抽屉，展示本轮主结果、真实模型交付状态和回答覆盖；按排名列主结果及关联证据，可在条目内展开文字或图片 | 证据失效在原处提示，始终不再打开第二个原文窗口 |

正文编号只读对应会话及 Run 的引用。PDF 原文由同一引用接口的 `source_pdf=true` 分支获取，服务端核对 Run/Spec、冻结证据、当前资料库读权和原发布版本；默认内容接口仍返回冻结摘录。关闭抽屉中止对应请求并释放预览资源。

## 数据、状态和验收

已启用问文且本轮已冻结授权资料范围时，分类为通用对话的解释类问题先走文档检索；明确的问数和混合请求沿用各自路由。未命中可引用资料时，说明资料不足，不补写无来源答案。刷新或打开历史会话时，从轮次的 `assistant_item` 恢复已保存的回答与引用。

发问时重新核验 Agent 及库资格，冻结 Agent 版本和本次授权范围；数量、排序按 Runtime 结构化约束和实际能力呈现。来源沿命中→装载→发送→引用记录；未发送和未知交付均不能标作已使用。消息与流事件绑定会话和运行标识；换会话、切域终止对应前端流并隔离迟到事件。空态区分无可用 Agent、空会话、仅可问数、运行失败及证据不足。窄屏会话轨按本平台 AIOps 工作台方式收展，工具栏换行，输入仍可达；引用按满宽证据抽屉呈现并返回原焦点。

验收：在各平台与其 AIOps 工作台对照会话轨收展、工具栏、空会话、消息、正文长滚动、底部输入及窄屏；不出现诊断专属动作。原会话可开，无读权不显示敏感绑定名，问数不被误拦，引用仅含实际发送且使用的证据；读图失败、流取消和历史不可读有真实反馈。

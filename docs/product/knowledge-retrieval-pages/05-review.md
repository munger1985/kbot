# 05 · 资料审批（知识库文件页内）

[整体设计](../knowledge-retrieval-ui-alignment.md) · 合并到[知识库文件](06-files.md)，无独立页面。新资料只需审批一次，解析和索引校验成功后由后台自动发布；审核和撤回分别核权，无手动发布入口。

## 信息与操作

- 队列按实际授权展示待审核、已发布、已拒绝；索引进度在解析任务页查看。行显示文件及精确版本、库、提交时间、审核状态、处理阶段、发布状态；不得把状态合并成「通过」。
- 审核详情提供授权的安全预览、版本、处理事实和审核意见，不提供下载。等待审批的版本通过时必须选择[三档解析](../knowledge-library-parse-strategies.md)之一；展示当前库模型可用性和禁用原因，提交时后端再校验并冻结所选档位、模型版本。拒绝不要求选择，不启动解析。并发决定已提交时刷新该版本，不能覆盖它。通过后进入解析，启用库内索引校验通过自动发布，无需二次确认。
- 历史已完成但未发布的资料可通过单文件重建自动发布。撤回是独立的危险操作，确认说明停止新检索，且不会删除文件或把历史引用换成新版。

## 数据、状态和验收

复用 review/withdraw、精确版本及核权原文端点；按岗位展示队列和允许操作。提交决定时防重；若状态或权限改变，保留可保留的意见并提示刷新，不能自动更换目标。审批抽屉不展示解析重试或上传。加载、无任务、筛选空、数据冲突、没有安全预览、待索引及无法发布各有状态；窄屏列表与详情分层。危险操作复用确认，反馈区域可被辅助技术感知。

验收：未审批不调用解析模型；无 OCR 禁用自动判断和视觉增强；OCR 加 VLM 才可选视觉增强；拒绝不排队；审批通过、索引校验后自动发布，无需手工发布权限；并发不覆盖决定；撤回后旧检索不可读；详情不泄漏列表不可见的版本。

## 文件页内交互

- 文件行旁显示有权处理的「审批」。文件行若显示已发布版本，审批按钮单独定位待审批版本；抽屉内预览该精确版本并提交决定，不在审批抽屉内切换版本。已发布队列按权限提供「撤回」。
- 单文件审批打开时，若当前知识库允许「自动判断」，默认选中该解析方案，审批人仍可改选其他可用方案。若「自动判断」不可用则不预选其他档位，显示不可用原因。通过和拒绝均可不填审核意见；打开抽屉或选择方案都不会提交审批，须明确点击通过或拒绝。
- 「待审批」以版本为行，在当前库、当前页勾选；批量通过时必须明确选择所选版本共同支持的解析方案（历史任务无须选档），批量拒绝不带方案。复用确认交互和单版本审批接口，逐条提交并重新核权；分开报告成功和未确认结果，不自动重试。审批通过只表示决定已提交；启用库内首次索引校验通过后才自动发布。切库、切页或刷新后清除勾选。

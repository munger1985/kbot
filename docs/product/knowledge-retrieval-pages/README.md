### 视觉评审共同输入

两端是同一工作流、不同宿主壳。参考源码中真实 AIOps 目录、右抽屉、工具栏、按钮、反馈与共享 token；保留知识检索的主题机制。原型主要面向距离屏幕约一臂的企业知识使用者、贡献者、审核／发布人员和库管理员。整体气质安静、务实、可核对；让用户先理解当前范围和单一主动作，再看证据或下一步。以「库 → 版本 → 证据」的身份链和「处理／审核／发布分轨」作为跨页视觉母题，避免通过颜色暗示已可查或已完成。壳层只显示工作域，不追加项目未授权的功能。真实线上数据非必要：使用一套显式标注的评审夹具，围绕《巡检交接规范》及其同库相关资料；预览采用夹具文本排版，不伪造现场图片或模型效果。

三方向评审稿采用桌面 1440×900 比较与 390px 窄屏校验，仅作选择依据。Agent 问答以现行 AIOps 页面为视觉基准，其余页面以各自已确认方向为准。生产仍复用 Portal／KBot 现有可访问控件，不以原型代码替代。

正式设计与选稿记录保存在两仓；外部目录只保留评审 HTML、截图及索引。方向已确认，未进入生产实施。

# 07 · 知识库管理

[整体设计](../knowledge-retrieval-ui-alignment.md) · KBot4：`knowledge-cores.html`；Ammolite：`manage/libraries`。App 管理 + 具体库 MANAGE；新建只需 App 管理资格。只管理库，不嵌文件操作、上传、审核、检索或问答组件。

## 信息与操作

- 卡片目录复用「运维知识库」的资源容器、工具栏、状态徽标和底部操作栏：搜索名称／说明／库标识，按启停筛选。卡显示名称、简述、状态、更新时间、授权成员数和当前修订。主操作为「编辑／成员」；「更多」包含「停用／启用」和「删除」，不再打开重复展示卡片信息的查看抽屉。可跳文件或 Agent 管理，但不内嵌文件列表。
- 新建和编辑用同一右抽屉（桌面上限 820px，窄屏满宽），名称必填、说明可选。字段约束随合同；先做空白、本地长度提示，再由服务端规范化及同域去重。编辑区按职责配置当前库的模型，不设置解析方案。模型区问号打开独立右抽屉，以[三档对照表](../knowledge-library-parse-strategies.md#创建和编辑知识库)说明每档效果及模型要求；关闭返回原表单并保留输入。固定标题与按钮、中间滚动；保存中防重，错误保留输入；冲突要求刷新后重新编辑。未保存退出采用共享放弃确认、Esc 和焦点回归。
- 新建在同一个抽屉内完成两步：填信息和选模型 → 确认检索能力。第 2 步分别展示「文搜文（关键词检索）」「文搜文（语义检索）」「文搜图」「图搜图（找原图）」「图搜图（找相似图）」。文搜图和找相似图分别说明模型及索引要求；未选 VLM 时不能使用视觉增强解析，在表格下单独说明，不改变检索配置状态。可返回修改，保留输入；点「确认创建」才提交。
- 编辑已有库，只有向量模型变更需复核：按文本／视觉分别列出新增、更换或解绑，并展示当前已发布文件数。有已发布文件且新增或更换时，可「仅保存」或「保存并重建」；仅保存后也可在[解析任务](04-processing.md)开始。解绑保存即关闭对应向量方向，不影响关键词和找原图。只改 OCR／VLM 不重建索引。
- 卡片上的「成员」直接打开右侧权限矩阵，采用已确认的 **方案 B**。矩阵仅管理当前知识库的个人授权，不配置组、App 角色或跨库规则。
- 停用确认说明禁止新上传、新检索和新绑定但保留原资料。点击「删除」先按库读取最新管理状态并核对卡片修订；有资料、被当前／历史 Agent 引用或版本变化时直接提示原因，不进入确认。通过检查才弹出危险操作确认，确认后由服务端再次验证并删除。不提示自动解绑，也不把停用叫删除。按钮可见性以实际能力和当前权限为准。

## 数据、状态和验收

管理态 list/detail 与 READ 使用态分开；停用库仍可管理。文本、视觉 Embedding 均可选，新建成功直接启用，不设草稿状态。模型选择区明确未配置文本 Embedding 时，新资料不支持文本语义检索，仍可按关键词检索；已配置也须等匹配的索引发布后才能语义检索。复用 create/PATCH 与版本号，删除用 If-Match。删除事务锁库并复核资料及历史引用，同一锁约束覆盖上传、删除、Agent 绑定；同名竞态两数据库单独验证。列表统计不可用于授权或最终删除判断。加载、无库、筛选空、保存失败、失权、版本过期与存在依赖各用独立反馈。

验收：管理页找不到文件操作和解析档位选择器；按库模型可保存，说明抽屉能用键盘打开并正确回焦；停用后可编辑但不可新用；只被历史 Agent 引用也不可删；授权列表不泄漏主体；窄屏抽屉滚动和焦点恢复正确。

## 已确认布局：A · AIOps 式卡片目录

- 顶部紧凑工具栏，下方与 AIOps「运维知识库」共用固定规格网格：宽 312px、宽高比 5:6、卡间距 14px，随容器宽度自动换列，窄于 312px 时同尺寸收缩。新建卡为第一张且与普通卡等大，工具栏不重复添加新建按钮。启用／停用同在一个目录，由徽标与筛选区分，不设常驻管理摘要或启停分栏。
- 新建、编辑和成员授权沿用标准右抽屉；启停及删除走二次确认，保留筛选和来源卡片。空列表仍有授权的新建入口，卡片不承载文件操作。

## 成员授权抽屉：B · 权限矩阵

- 一人一行、一权限一列：读取已发布资料、上传资料并处理本人可操作的任务、审核资料、撤回发布、管理此库与成员。读取随成员身份生效，不单独关闭；管理不自动授予其他列。发布和重建索引切换由后台自动完成，不再设置独立发布权限。矩阵表示本库授权，不代表用户的最终操作资格；实际执行仍检查 App 权限。
- 「已授权 / 可添加」区分修改和加入。按姓名或成员 ID 搜索，行内显示完整成员 ID 以区分同名；两类勾选分开保留，搜索和分页不改变已选范围。可单独加入，也可批量加入，初始仅有读取。已授权成员可逐格编辑；同时勾选多人时，可批量追加或撤销上传、审核、撤回中的一项，不覆盖未选择的权限。窄屏仅矩阵区域横向滚动，抽屉标题和底部复核按钮常驻。
- 候选只来自当前工作域经服务端验证的 App 成员。只有具备相应 App 资格的人可以获授管理；最后一名有效管理员不能被移除或撤销管理。现存失效成员可暂存移除；失去管理资格的有效成员可撤销原管理授权。成员目录读取失败时显示只读授权和重试入口，不允许盲写。
- 加入、移除和调整权限只写本次抽屉草稿；底部显示变更人数，复核时按人列出新增、撤销、移除。取消复核保留草稿；关闭未保存抽屉走共享放弃确认。最终确认后用原有 `PATCH` 和 `expected_revision` 一次保存；服务端复核候选与管理员。版本或资格冲突时冻结保存、保留草稿；显式读取最新版本后只合并本次改过的权限，不覆盖其他人的无关改动，不自动加回已被他人移除的成员，并提示重新复核。

# 06 · 知识库文件

[整体设计](../knowledge-retrieval-ui-alignment.md) · KBot4：`files.html`；Ammolite：`files`。此页合并原「上传资料」和「资料审批」。浏览需 App 使用权限 + 库 READ；添加还需 App 上传权限 + 启用库 UPLOAD。直接检索和解析任务仍独立。

## 信息与操作

- 先选可读库，按标题与可披露发布状态过滤。文件名列不显示版本 ID；查看或审批抽屉保留精确版本。普通列表的「状态」列每行只展示一个徽标：待审核的未发布版本显示「待审核」，其他记录显示「未发布」「已发布」或「已撤回」。审批队列的「审核」「发布」列各显示一个独立状态。打开文件默认展示当前可读版本，不从最新版本猜发布版本。
- 右侧详情列出有权查看的版本和发布／撤回状态、原文、页码／段落定位。可见的未发布版本遵循贡献者本人或岗位授权，普通读者不因拿到 ID 就可读。历史证据入口仅按精确身份处理，无权时不回落到其他版本。
- 文件行按实际授权显示「审批」，打开精确待审批版本；待审版本不是当前展示版本时显示「审批其他版本」，不改变当前展示版本的状态。待审批队列支持勾选后批量通过或拒绝；新资料索引校验成功后自动发布；有相应权限可在本页撤回；历史未发布文件可单文件重建后自动发布。详见[资料审批](05-review.md)。
- 查看抽屉直接载入精确版本的原文预览，不提供下载入口。浏览器支持时内联 PDF、PNG/JPEG/WebP；纯文本与 Markdown 按文本显示（最多前 64 KiB，不渲染 HTML）；不支持的格式只提示不可预览。PDF 使用浏览器支持的参数隐藏原生工具栏，图片预览禁用右键菜单与拖出；这些是界面限制，不能防止用户另存或截图。预览由 BFF 每次核权；切版、切库或关抽屉时清除旧预览。
- 「上传资料」打开右抽屉，目标库锁定，不可在抽屉内切换；支持多选或拖入，逐文件提交、回执和审核，失败项用原幂等键重试。已接收记录刷新目录，不代表发布。关闭有未提交文件的抽屉时确认放弃。

## 数据、状态和验收

已审核通过的失败文件仍保留原始资料及审核意见；重新解析和索引重试从[解析任务](04-processing.md)操作，无须重新上传或审批。已经发布的文件不会因索引重建改动文件版本或原文预览；候选索引由后台自动采用，不从本页发布。

复用 documents 列表与 source 预览，提供文件／版本精确详情和后端标题／状态筛选。列表先按作用域和版本资格裁剪再分页；只返回受许可的版本、文档标题和统计。切库和权限变化清空当前选中与预览。加载、空库、无匹配、无权限和版本无预览各有状态，窄屏抽屉满宽且原文不横向溢出。

验收：标题搜索只匹配目录；普通读取者不见他人的待发布件；预览定位到正确版本；撤回或失权后旧链接不绕过读取策略；主动内容不内联。

## 已确认布局：B · 左侧库列表

- 左侧展示可读库与「可上传／只读」，右侧保留标题与发布状态筛选及文件表格。未选库时提示先选择，精确链接按已核权的库定位。使用行内「查看文件」进入右侧版本与原文抽屉；对可上传的当前库显示可用的「上传资料」动作。
- 关闭后回到原行及当前筛选；窄屏行按标签呈现，满宽抽屉保留精确版本、位置及预览。
- 查看文件和审批均沿用 AIOps 运维资料的右侧详情抽屉样式：文件名为主标题，原操作名为眉题，使用相同的标题栏、信息卡、分区与留白。正文独立滚动，审批动作固定在底栏；两种抽屉保留各自的字段和预览能力。

## 已确认上传抽屉：A · 拖放优先

- 顶部显示锁定的目标知识库与上传权限，随后是带「选择文件」按钮的大拖放区，库的大小及格式限制紧跟入口。选文件或拖入只加入本次清单，不立即提交。
- 清单逐行显示文件名、类型、大小及待提交／接收失败／已接收状态。失败行保留原因；未接收项可移除，已接收项可查看解析任务。
- 固定底栏汇总数量，提交后部分失败只重试未接收项；全部接收后显示「完成」。已接收表示进入待审核，不自动发布。

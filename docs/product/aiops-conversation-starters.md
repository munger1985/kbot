# 智能运维新会话功能引导

## 产品目标

用户选择逻辑 Target 和 Agent 后，新会话不再只显示空白提示，而是展示与当前数据库类型、
连接状态和 Agent 绑定一致的功能菜单。用户仍可在聊天框自由提问；输入框旁的“功能”按钮
可以随时重新打开完整菜单。

## 功能分组

- 常用功能：全面健康、当前性能、阻塞与长事务、空间趋势；
- 性能报告：AWR、AWR Diff、ASH、单 SQL 深度分析；
- 诊断检查：备份恢复、复制、归档/FRA、最近错误、无效对象、参数；
- 实施文档：ADG、RAC、RMAN、RU、升级、迁移、克隆、Data Pump 和 ADG 演练。

Oracle 专属功能不会出现在 MySQL/PostgreSQL Target。Target 未启用、未配置只读连接或连接
不可用时，功能显示不可用原因，不会提交一个注定失败的 Turn。

## 交互规则

1. 无参数功能点击后立即创建 Turn；
2. 时间区间、SQL_ID 等参数先在紧凑表单中填写；
3. AWR 使用时间区间，由服务端结合快照目录确定快照号；
4. AWR Diff 强制两个区间等长；
5. 点击功能仍生成可读的用户消息，Conversation 历史和审计链保持完整；
6. 菜单不是 Assistant 问候消息，不写入数据库。

实施文档入口只生成只读取证后的操作文档，不直接执行数据库变更。

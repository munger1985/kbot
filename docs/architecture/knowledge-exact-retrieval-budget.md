# 已发布知识索引的分批检索

知识检索与 AIOps 的知识召回共用本规则。按请求核验授权范围、发布版本、允许视图与索引代次。命中、章节、原文定位及续取仍使用已冻结的快照，不从原文件绕过允许视图。

- 先逐批核验现有投影对象的摘要和身份，只保留文本、定位、图片指纹及向量空间目录。现有投影对象内混存文本和向量，首次扫描仍会顺序读取每个对象的字节；非向量通道不实例化向量，也不为评分重读向量批次。
- 同一服务进程按 Domain、Tenant 和完整授权版本快照复用索引元数据；快照包含版本集合、允许视图、索引代次和状态修订。缓存使用有大小、条目数和时效上限的 LRU，不包含向量、查询结果或用户授权。每个请求仍核验当前权限和发布指针，证据期限取自本次 Scope；换版或撤回后不会使用旧元数据回答。
- 关键词统计覆盖整个授权索引，保留原 BM25 分数、稳定排序与游标；同图匹配使用原图摘要。语义或视觉向量通道只比较与冻结查询空间一致的表示，按批解码和评分，在全范围内稳定合并后才截取候选，不以局部排名代替全局排名。
- 不累加全库向量文件大小作为内存预算。单对象字节数、单批表示元素数、常驻元数据总字节数、文本量、单元数与超时仍有明确上限。索引读取的资源超限作为服务资源错误，和输入合同校验区分；向量通道失败如实记录，不声明成功。
- 只在确实加载证据时写入对应的不可变文本对象。已发布索引和资料无需重建或迁移，不修改系统级 TOML 或数据库 Schema。
- 知识库直接检索首屏只组装主命中及其关联组。未展示候选仍保留在内部回执；首屏只为主文本命中组装完整段落、章节和文字预览。小文本预览按内容句柄去重、分批读取，发送前统一复核授权和快照；关联正文、段落上下文与 PDF 原文按点击读取。
- 直接检索默认查文字与表格并展示主命中的关联图；显式选择「图文混合」或「图片与页面」时仍可用文字搜图。关联展开只从当前页主命中出发，不为未展示候选逐条展开；Agent 的完整证据流程保持不变。无关的孤立字母不占普通正文结果名额，明确查找该字母时仍可命中。直接检索证据只在阅读区预览，格式不支持时不回退到附件下载。

KM Portal · Query Lifecycle

用户提问后，系统如何生成最终回答

一次 Router 规划，两条受控执行路径；Asset 结果必须经过证据与引用校验。

LLM 调用 Oracle 数据库 关键词 / 向量检索 确定性代码
公共入口与规划
01 · INPUTUI

用户提问

KM Portal Chat 接收问题、会话 ID，以及用户当前可见的授权范围。

02 · GATEWAYAPI + DB

Main API

校验用户与 Domain 权限，创建 Turn，并把运行请求提交给 Agent Runtime。

03 · SNAPSHOT确定性代码

冻结运行上下文

Unicode 判定回复语言；冻结 Agent 模型、策略、会话上下文和资源范围。

04 · PLANRouter LLM

Planner 生成查询合同

理解多条件、数量、排序与追问，输出 KmPortalRequestPlan.v1。

05 · VALIDATEPydantic

合同校验与路由

规范字段并拒绝无效合同，只允许 PORTAL_HELP 或 ASSET_SEARCH。

产品介绍 / 使用帮助
PORTAL_HELP
H1 · LANGUAGE确定性代码

选择回复语言

从冻结语言选择中文、英文、日文或韩文内容。

H2 · CONTENTMarkdown

读取预置介绍

读取并缓存对应 Markdown；不调用 LLM、数据库或知识检索。

H3 · OUTPUTSSE

流式返回帮助

直接输出统一产品介绍、功能说明和典型提问方式，不生成引用。

Asset 搜索 / 问数 / 详情解释
ASSET_SEARCH
A1 · CONTRACT确定性代码

AssetSearchPlan

冻结条件表达式、数量、排序、投影及证据要求。

A2 · METADATAOracle DB

托管元数据查询

按 Domain、READY、作者、时间、产品等条件执行计数、筛选和排序。

A3 · EVIDENCEKC 检索

正文证据检索

在候选 Bundle 内组合关键词检索与向量检索，获取 Asset 正文证据。

A4 · QUALIFY确定性代码

资格与证据收敛

按布尔条件、同 Bundle 约束和语义支持度剔除噪声候选。

A5 · COMPOSE LLM代码

Composer 生成回答

简单计数/分组确定性排版；正文解释与详情由 Composer LLM 基于证据生成。

A6 · OUTPUT校验 + SSE

引用校验并返回

验证每个 Asset 的 C 引用，再流式返回答案和可打开的 Asset 引用列表。

原则：Planner 决定“怎么查”，检索与数据库决定“查到什么”，Composer 只能使用已验证结果。 KM Portal · Agent Runtime · 2026

问数模型

问数模型是已发布的语义数据模型，而不是 LLM 或数据库连接。它复用现有 Data Query 的安全执行与审计能力。

语义模型

只有 PUBLISHED 版本才允许由 Agent 绑定和执行。

名称Domain数据源版本状态绑定 Agent
尚无问数模型

接入后在此管理真实的语义模型草稿、验证、审核、发布和策略绑定，不展示数据库凭据。

发布前流程

LLM 不能生成或执行自由 SQL。

  1. 连接与 Schema 发现读取允许 Schema，采集受选对象结构。
  2. 语义模型草稿定义 Dataset、指标、维度、关系和口径。
  3. 测试与发布以问题验证后审核、发布版本。
  4. 策略与 Agent Binding再允许对应 Agent 使用问数能力。

创建问数模型草稿

创建的是语义模型草稿。它完成验证、发布和 Policy Binding 前，不能被任何 Agent 执行。

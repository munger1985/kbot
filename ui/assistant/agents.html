创建 Agent

  1. 基本信息名称、说明、当前 Domain 与草稿指令。
  2. 绑定 Knowledge Core必填；只能选择当前 Domain 的 ACTIVE KC。
  3. 选择问数模型可选；只允许已发布且策略有效的模型。
  4. 模型与授权绑定 Router/回答模型、成员与角色后才允许启用。
向导控件将在资源 API 接入后逐步启用。当前不会创建无 KC Binding 的伪 Agent。

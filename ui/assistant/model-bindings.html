模型绑定

模型名称、端点与 Secret 只由模型目录管理。智能工作台只绑定已启用且能力已经验收的模型引用。

App 模型角色

每个角色分别绑定；前端和 Agent 指令都不写死模型名称。

角色绑定模型能力要求状态最近验收
知识回答等待模型目录文本回答未绑定—
X 实时搜索等待模型目录X Search、引用、流式响应未验收—
文生图等待模型目录图像生成、产物返回未验收—

能力矩阵

能力未验收时，对应业务入口不能创建 Run。

  • X Search工具调用、真实引用、用量与错误语义
    待验收
  • 文生图图像产物、MIME、尺寸、对象存储转存
    待验收
  • Responses 流式响应工具进度、终态恢复与稳定请求 ID
    待验收

配置模型绑定

页面不会配置 OCI Endpoint、请求签名或 Secret。保存前由服务端复核模型状态、能力和 App 管理权限。

STEP 01

角色信息

说明这个 Agent 面向谁、负责什么。

新增 Agent 固定保存为草稿；确认资源后再启用。

STEP 02

工作范围

决定 Agent 可以查看哪些系统、完成哪些任务、使用哪些知识。
允许访问的业务系统必选，最多 32 个；只显示已上线系统。
开放能力一次提问可以组合多项能力。
运维知识只检索已审批版本，并在回答中保留原文引用。
绑定运维知识库至少一个，最多 32 个；选择器支持搜索和分页。
知识标签范围不限制标签，使用所选知识库中的全部已审批知识。

STEP 03

自动化

自动触发不影响聊天、知识问答和报告查询。
自动告警诊断按告警级别、资源重要程度和冷却时间触发。

STEP 04

模型与指令

运行中的 Agent 必须配置规划和回答组织模型；启用智能诊断时还必须配置诊断模型。

STEP 05

确认配置

核对业务范围、知识策略和模型角色后保存。

创建 AIOps 自建账号，初始角色仅授予当前业务空间。

至少12位，包含大小写字母、数字及特殊字符；首次登录需修改。
留空不接收个人飞书通知，站内通知正常；填写后需本人验证。
如何获取 open_id？
  1. 打开飞书 API 调试台，选择通知渠道使用的同一个自建应用，找到“发送消息”接口。
  2. 将接收者 ID 类型设为 open_id，点击“快速复制 open_id”，搜索并选择该用户。无需实际发送消息。

同一个人在不同应用中的 open_id 不同。查看官方说明

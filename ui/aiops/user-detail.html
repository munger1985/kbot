如何获取 open_id？
  1. 打开飞书 API 调试台，选择通知渠道使用的同一个自建应用，找到“发送消息”接口。
  2. 将接收者 ID 类型设为 open_id，点击“快速复制 open_id”，搜索并选择该用户，点击“复制成员 ID”。无需实际发送消息。

open_id 以 ou_ 开头；同一个人在不同应用中的值不同，不能使用其他应用的 open_id、user_id 或 union_id。查看官方说明

保存只登记身份；新增或更换后，需本人到“我的通知设置”完成验证码验证。

KBot 4.0 测试台

Vanilla JavaScript · Main API only

使用方式

页面只访问公开 /api/v1。请通过本地 HTTP Server 打开， 并在 Main API 的 CORS 白名单中允许该 Origin。 

python3 -m http.server 8088 -d ui
# 浏览器访问 http://127.0.0.1:8088

Knowledge Core

Collection、单文件/Bundle 直接入库、状态跟踪和 Agent Binding。

Agent 问答

Conversation、文字/图片提问、SSE 事件、历史记录和最终 Artifact。
